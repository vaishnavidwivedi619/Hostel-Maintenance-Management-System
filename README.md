# Hostel Maintenance Management System

Responsive frontend app (HTML, CSS, JavaScript) where hostel residents log maintenance complaints, track resolution status, and receive notifications.

## Features
- Complaint form: Room Number, Category (Electrical / Plumbing / Furniture / Wi-Fi), Issue Description
- Status pipeline: Registered → Assigned → In Progress → Resolved (stages cannot be skipped)
- Roles: Student, Warden (assigns staff), Maintenance staff (updates progress)
- Notifications on every status change; filters and search; data saved in localStorage
